# LawIntake

> SaaS for small law firms to automate client intake and document collection.

## Overview

LawIntake automates the client intake process for small law firms — from initial contact through document collection and case setup — so attorneys spend their time on legal work, not administrative overhead.

## Goal

Ship the intake automation MVP.
